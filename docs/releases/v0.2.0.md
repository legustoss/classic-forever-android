# Classic Forever v0.2.0 — release notes (draft)

Version: `0.2.0` (`versionCode = 3`). Tag: `v0.2.0`. Status: **prepared, not published**.

This is a minor release: it adds user-facing features (frame generation and a component manager) and a significant launcher/Quick Menu rework.

## Highlights

- **Frame generation (LSFG-VK):** the launcher can import a user-provided `Lossless.dll`; settings are applied off the UI thread with debouncing. The DLL is never bundled.
- **Runtime components in Settings:** recommended built-in components, a downloadable v16 Proton test build with SHA-256 verification, local file import, explicit active-slot status, and one-tap reset to bundled components. Both download and import now write into the slot actually used at launch. `tools/` and bundled binaries in git are unchanged.
- **Launcher UX:** Main / Settings / FirstInstall screens, compact community buttons with icons, compact landscape layout, server online counter hidden until a real data source exists.
- **Gamepad support in the launcher:** connection hints with icons, A confirms and B navigates back; in-game input behavior is untouched.
- **In-game Quick Menu:** settings grouped by category, with a 180 ms debounce on LSFG apply to avoid frame drops when changing the target FPS.
- **Login dialog:** no hardcoded "Battle.net" text, styled like the launcher and localized.
- **Reliability:** explicit launch only (no auto-start), robust back bar, `WineInfo` multi-digit version-code fix, container directory reuse, obsolete `SDK_INT` guards removed.

## Compatibility and validation

- Proton v16 works on the user's device but showed **no clear FPS advantage** over the built-in Proton in the city test on a Poco F7 (35–40 fps at native resolution / 50% render scale). The built-in Proton remains recommended; v16 stays an optional downloadable/test component.
- A 32-bit-trimmed variant of the proven component is available for testing only.
- Client version check remains no-op until the server exposes bounds; player count remains hidden.
- Adreno 750/735/825 remain "pending validation" until in-world reports exist.
