# Classic Forever 0.2.0

Коротко: добавили генерацию кадров, управление компонентами и переделали настройки лаунчера.

## Нововведения

- Генерация кадров через LSFG. Можно подключить свой `Lossless.dll` и включить её в настройках. DLL не идёт в сборке.
- Управление компонентами. В разделе «Графика» можно скачать тестовый Proton 16, импортировать свой файл и одним нажатием вернуться к рекомендуемому набору. Активная версия определяется по хешу установленного файла.
- Настройки разделены на три вкладки: «Лаунчер», «Игра» и «Графика». Компоненты разложены по раскрывающимся спискам, у каждого списка по одной кнопке импорта.
- Геймпад в лаунчере: A подтверждает, B возвращает назад. В игре управление не менялось.

## Улучшения

- Интерфейс в портрете стал компактнее: одна кнопка «Назад» внизу, в ландшафте сверху. Кнопки больше не растягиваются на весь экран.
- В сообществах теперь иконка Discord вместо универсальной.
- Quick Menu сгруппирован по категориям. Изменение целевого FPS и настроек LSFG применяется с небольшой задержкой, чтобы не проседали кадры.
- Встроенный Proton остаётся рекомендуемым. Замер в городе на Poco F7 показал примерно одинаковые 35–40 FPS с v16, заметного выигрыша нет.

## Исправления

- Показывается только драйвер под обнаруженный GPU. Если модель неизвестна, видны оба драйвера с предупреждением.
- Кнопки скачивания и импорта больше не сжимают названия компонентов в портретном режиме.
- Онлайн-счётчик и версия клиента скрыты, пока сервер не отдаёт реальные данные. Никаких выдуманных чисел.
- Исправлена проверка версии Wine с несколькими цифрами и повторное использование каталога контейнера.
