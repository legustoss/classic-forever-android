# Classic Forever 0.2.0

Frame generation, component management, and a reworked launcher are the big changes here.

## Features

- Frame generation with LSFG. Bring your own `Lossless.dll` and switch it on in Settings. The DLL is not bundled.
- Component management. The Graphics tab lets you download the optional Proton 16 test build, import a file, and return to the recommended set with one tap. The active version is identified by the hash of the installed file.
- Settings are split into three tabs: Launcher, Game, and Graphics. Components sit in expandable groups, with one import button per group.
- Gamepad support in the launcher: A confirms and B goes back. In-game controls are untouched.

## Improvements

- Portrait layout is tighter: one Back button at the bottom, and the top-bar one in landscape. Buttons no longer stretch across the screen.
- The community row now uses the Discord logo instead of a generic icon.
- Quick Menu is grouped by category. Target FPS and LSFG changes are applied with a short delay so the game does not drop frames while you adjust them.
- The built-in Proton is still the recommended option. A city run on a Poco F7 showed about the same 35–40 FPS with Proton 16, with no clear win.

## Fixes

- Only the driver matching your GPU is shown. If the GPU is unknown, both drivers appear with a warning.
- Download and import buttons no longer squeeze component names in portrait mode.
- The online counter and client version stay hidden until the server provides real data. No made-up numbers.
- Wine version parsing handles multi-digit versions, and the container directory is reused.
